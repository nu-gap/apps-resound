Adding a Module Help File

You can provide a Rich Text file that describes your module.  In this file you should give at least your module's name and version, your personal name and email address, and helpful information about the module.

To get Resound to load this file, it must be called ModuleInfo.rtfd
Note that ordinary .rtf files are not valid: the file must be an .rtfd file.

Put this file in your .rmod bundle, or in a localized subsection (Resound should load the proper localized version).  One way to do this is to add the file to your ProjectBuilder module project under the "Other Resources" category.

After it has loaded the module, the file will show up as a menu item under Resound's "Module Info" submenu (in the "Info" menu).
